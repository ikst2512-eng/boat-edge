# BOAT EDGE V408｜ローカルB（番組表）→V402形式JSON変換（2026-10-14）

研究用ドラフト PR #253、01/03・正式Fresh・本番予想・学習済み重みを変更しない。実データ利用許諾・5年分の取り込み・精度改善はまだ未確認。

## 成果

V407でローカル成績Kの解析からV401用JSONへの変換を自動化したのに対し、V408は**日別の番組表B TXTをV402用の全レースB-only名簿に変換**する。V407が要求するB名簿も同じ形式なので、両方を1日分ずつオフライン接続できる。これによりK/B各レースを手作業でJSON化する必要を減らした。

- 運用者が取得権利を確認して合法的にローカル保有する、解凍済みCP932（Shift-JIS系）B TXTのみ入力する。ライブラリ boatrace-lzh 0.1.0 の ScheduleParser.parse と parse_schedule_with_close_times を任意導入して利用。ライブラリのダウンローダーや外部APIは使用しない。
- 1〜24場、1〜12R、6艇に1人ずつ、選手ID4桁の重複なし、同日JST締切予定時刻の一致、全レース名簿と締切の対応が完全一致することを必須とする。欠損・曖昧な情報は補完しない。
- 2021-10-01〜2026-09-30だけ許可し、2026-10-01以降のFormal Freshをハード拒否。
- Bは予想側の入力なので、進入・実際の着順・結果・払戻フィールドは書き出さない。

## 実行（許諾済みローカルファイルのみ）

    PYTHONPATH=scripts python3 scripts/boat_edge_v408_local_b_program_bridge.py --local-b-txt /private/authorized_B_20260930.txt --source-day 2026-09-30 --output-json /private/B_staged_20260930.json

続いてV407でローカルのK TXT + V408出力B名簿 + 取得時刻の外部証拠マップを読み込み、V401→V402で同日B/Kを独立照合、V406で日別パッケージを結合しV404/V405の履歴特徴量へ渡す。**K公開日時は生データだけでは独立検証できず、V407は根拠ある公開時刻マップが無ければ停止する。**
